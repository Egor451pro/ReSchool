# UX-аудит (роли)

Проверено по сценариям завхоза, фрилансера и аналитика (код + структура экранов). Полный live-обход в браузере требует поднятого Postgres (`npm run db:up`).

## Исправлено в этой итерации

- Главная: вход выше сценария, визуально отделён карточкой.
- Скелетоны `loading.tsx` под новый layout и кабинетные сетки.
- Offline-баннер с кнопкой «Повторить».
- Focus-visible на кнопках, полях и ссылках.
- Короткий fade-up при появлении секций (`prefers-reduced-motion` учитывается).
- Дистанция на бирже/заказе (haversine по координатам учреждений); пункты утиля и шаги сдачи. Картографический виджет убран.
- Error / not-found с кнопкой повтора.

## Наблюдения для следующих проходов

- После установки Docker Desktop прогнать полный клик-путь: регистрация → карточка → claim → подтверждение цены → завершение / утиль.
- На узких экранах проверить горизонтальный `SectionNav` и высоту кнопок (уже `min-height` на mobile).
- Геокод при регистрации идёт через Nominatim; без сети адрес сохраняется без координат, сортировка по дистанции деградирует.
